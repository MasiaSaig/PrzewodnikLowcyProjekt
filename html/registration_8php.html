Function that creates new hunter

If username or password are empty, hunter cannot be created. Next username must be unique for a hunter. After that id_race and id_class must exist in database. Only after all the checks hunter can be created.

Parameters
[in]$usernameName of hunter.
[in]$passwordPassword of hunter.
[in]$password_repeatRepeated password, must be the same as $password.
[in]$id_raceRace of a hunter.
[in]$id_classClass of a hunter.
Returns
Returns empty string on successs, else return error message.
